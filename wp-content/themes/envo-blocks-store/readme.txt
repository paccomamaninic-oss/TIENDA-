== Description ==

Envo Blocks Store is a fast, lightweight and easy-to-use WooCommerce block theme for online stores. It includes a ready-made store home page, three headers, shop and blog sidebars, and styled product, cart, checkout and My Account pages, all easy to change in the Site Editor without code. No page builder and no theme JavaScript; without WooCommerce it works as a clean blog theme.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New Theme button.
2. Search for "Envo Blocks Store", or click Upload Theme and choose the theme zip file.
3. Click Install, then Activate.
4. Go to Appearance > Editor to customize templates, template parts and styles.

== Frequently Asked Questions ==

= Does the theme require WooCommerce? =

No. The theme works as a regular blog theme. When WooCommerce is active, the shop pages, the mini-cart and the account icon are styled automatically.

= How do I get the store home page? =

When Settings > Reading > "Your homepage displays" is set to "Your latest posts" (the default), the front page uses the theme's Home template: the store sections (hero with categories, promo strips, benefits, featured products, a welcome banner and new arrivals) around your latest posts, which are the main blog listing with pagination, followed by contact. If you choose a static page instead, your page is shown, and you can build it from the "Store home" page pattern or switch it to the "Store home (three-row header)" page template.

= Does the home page need WooCommerce? =

No. With WooCommerce active the product rows and the category list show your products and product categories. Without WooCommerce they show sample product cards made of regular blocks, which you can edit or delete.

= How do I add my logo? =

Open Appearance > Editor, select the header and click the Site Logo block to upload your logo.
